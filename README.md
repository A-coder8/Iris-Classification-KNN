# Iris Flower Classification 🌸
**Language:** [فارسی🇮🇷](https://github.com/A-coder8/Iris-Classification-KNN/README.fa.md)

 A machine learning project for Iris flower classification using **K-Nearest Neighbors (KNN)** with Python and scikit-learn.

The project predicts the species of an Iris flower based on four measurements of its sepals and petals.

## 📌 Features

- Iris flower classification using KNN
- Manual user input for flower measurements
- Input validation for numeric values and measurement ranges
- Model accuracy evaluation
- Built with Python, pandas, and scikit-learn

## 📊 Dataset

The dataset contains 150 samples from three Iris species:

- Setosa
- Versicolor
- Virginica

Each sample contains four features:

| Feature | Description |
|---|---|
| `sepal_length` | Sepal length |
| `sepal_width` | Sepal width |
| `petal_length` | Petal length |
| `petal_width` | Petal width |

The target variable is `species`.

## 🛠️ Technologies

- Python
- pandas
- NumPy
- scikit-learn

## ⚙️ Installation
Install the required libraries:

```bash
pip install pandas numpy scikit-learn
```

## ▶️ Usage

Run the Python script:

```bash
python iris_flower.py
```

Enter the four flower measurements when prompted. The model will predict the flower's species.

## 📈 Model

This project uses the **K-Nearest Neighbors (KNN)** classification algorithm.

The model predicts a flower's species by comparing its measurements with nearby samples in the feature space.

## 🎯 Project Goal

The goal of this project is to practice fundamental machine learning concepts, including classification, model evaluation, and handling user input.
