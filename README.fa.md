# 🌸 دسته‌بندی گل‌های زنبق با یادگیری ماشین

**زبان:** [🇬🇧English](https://github.com/A-coder8/Iris-Classification-KNN/blob/main/README.md)

این پروژه با استفاده از زبان برنامه‌نویسی پایتون و الگوریتم **K-Nearest Neighbors (KNN)** ساخته شده است و هدف آن پیش‌بینی گونهٔ گل زنبق بر اساس اندازه‌گیری کاسبرگ و گلبرگ آن است.

## 📌 امکانات پروژه

- دسته‌بندی گل‌های زنبق با استفاده از الگوریتم KNN
- دریافت دستی اندازه‌های گل از کاربر
- بررسی ورودی‌ها و محدودهٔ اندازه‌گیری‌ها
- ارزیابی دقت مدل یادگیری ماشین

## 📊 مجموعه‌داده

این پروژه از مجموعه‌دادهٔ Iris استفاده می‌کند که شامل ۱۵۰ نمونه از سه گونهٔ گل زنبق است:

- **Setosa**
- **Versicolor**
- **Virginica**

هر نمونه دارای چهار ویژگی است:

| ویژگی | توضیح |
|---|---|
| `sepal_length` | طول کاسبرگ |
| `sepal_width` | عرض کاسبرگ |
| `petal_length` | طول گلبرگ |
| `petal_width` | عرض گلبرگ |

ستون `species` گونهٔ گل را مشخص می‌کند و متغیر هدف مدل است.

این الگوریتم با بررسی نمونه‌های نزدیک به ورودی جدید، گونهٔ احتمالی گل را پیش‌بینی می‌کند.
